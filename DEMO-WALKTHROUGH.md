# Loom / MP4 demo walkthrough script

Target length: 3–5 minutes. Start the app with `npm install` and `npm run dev`, then record the browser and narration.

1. **Catalog (20–30 sec):** show the course cards, search/filter controls, and open a course.
2. **Course detail (30 sec):** show the course overview, learning outcomes, modules, and start a lesson.
3. **Classroom (60–90 sec):** play/pause and seek the video; click transcript timestamps and show that only the transcript panel scrolls; add a timestamped note and export notes.
4. **Resources (30 sec):** open a resource preview and generate/download a handout. If a real external resource is configured, show it opening in a new tab.
5. **Quiz (60–90 sec):** demonstrate a single-choice question, select multiple checkboxes, reorder sequence items with the arrows, submit, and show the answer review/explanations. Click **Retake Quiz**.
6. **Progress (20–30 sec):** return to the dashboard and show saved progress/certificate information.

Before sharing, verify the browser download completes and avoid showing personal browser notifications or private information.
